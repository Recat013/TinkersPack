# ---------------------------------------------------------------------------
#  TinkersPack - modifier slot deltas
# ---------------------------------------------------------------------------
#  One line per tinkerable item. The four numbers are how much to ADD to that
#  item's base slot counts, always in this order:
#
#      <item>            abilities  defense  upgrades  souls
#
#  A line of all zeros means "leave this item alone" - only items with at least
#  one non-zero number (or an entry in stat_overrides.txt) get a file written
#  into the datapack.
#
#  The trailing comment is what the mod currently gives that item, so
#  `abilities 1, upgrades 3` plus a delta of `1 0 2 0` lands at
#  2 abilities / 5 upgrades.
#
#  Notes:
#   - Deltas may be negative, but the result may not go below 0.
#   - Adding to a slot type the item does not currently have is fine; the type
#     is simply created. Same for items with no slots at all.
#   - Columns are split on whitespace, so line them up however you like.
#   - Blank lines and lines starting with # are ignored.
#
#  After editing, run:  python build_pack.py
# ---------------------------------------------------------------------------

#                                     ab  def  up  souls
